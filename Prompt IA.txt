Tu es développeur front-end expert en jeux de plateau web et directeur
artistique « cartoon gothique » (références : Corpse Bride, Adèle et la
Princesse, Little Nightmares — sinistre mais adorable).

Ta mission : construire un jeu de plateau COMPLET et JOUABLE nommé
« La Maison Hantée » (Le Manoir Grimm), variante du Jeu de l'Oie. Le jeu
reprend EXACTEMENT les mécaniques d'un jeu de l'oie modulaire existant
(« Le Jardin des Oies »), habillées d'un univers de manoir hanté :

- Un ÉCRAN D'ACCUEIL (« Le Vestibule ») où l'on choisit le NOMBRE DE
  JOUEURS (2 à 6) puis où CHAQUE JOUEUR CHOISIT SA CRÉATURE (son pion)
  et son nom — comme l'écran de préparation du jeu original.
- Un plateau de 63 pièces en spirale, régénéré au hasard à chaque partie.
- Des dés, des Cartes Chance, des Cartes Sortilège en main.
- 11 actions à poids réglables, rebond sur la case 63, victoire pile.

OBJECTIF N°1 : la page donne ENVIE dès le premier regard — sinistre à
première vue, adorable à la seconde.

LIVRABLE : un seul fichier HTML autonome (maison-hantee.html), 100 %
fonctionnel hors ligne, sans build, sans serveur.

ÉTAT EN MÉMOIRE (aucun localStorage) :
gameState = {
  board: [ { number: 1..63, actionId: String|null } ],
  players: [ { id, name, creature, emoji, color, bgSoft,
               position: 1..63, skipTurns: 0, hand: [actionId...] } ],

  config: {
    coverage: 45,       // % de cases 2-62 recevant une action
    cardDropProb: 35,   // % de Carte Sortilège reçue en fin de tour

    exactBounce: true,  // rebond obligatoire sur la case 63
    weights: { actionId: nombre 1-100 }

GÉNÉRATION ALÉATOIRE : à chaque « Entrer dans le manoir » ou « Mélanger
le manoir », les cases 2 à 62 reçoivent (ou non, selon coverage %) une
action tirée au hasard pondéré par les poids. Cases 1 et 63 : jamais.

TOUR DE JEU (dans l'ordre) :
1. Si skipTurns > 0 : décrémenter, journal « {nom} passe son tour »,
   passer au suivant.
2. Le joueur peut jouer 0 à N Cartes Sortilège de sa main (avant les
   dés) ; chaque effet s'applique immédiatement.
3. Lancer des dés (secousse CSS), puis avancée animée case par case.
4. Dépassement de 63 : REBOND — position = 63 − surplus. Ex. : en pièce
   60 avec un 7 → 63 − 4 = 59.
5. Pile sur 63 → VICTOIRE (§11). Sinon, si la pièce porte une action :
   l'appliquer immédiatement (message narratif au journal, animation du
   pion, chaînage possible si l'action en déclenche une autre, ex.
   Bougie Magique → Carte Chance).
6. Fin de tour : tirage aléatoire → le joueur reçoit une Carte Sortilège
   (cardDropProb %) tirée parmi les actions recevables en main. Main
   limitée à 3 : au-delà, la carte s'envole.
7. Joueur suivant (ordre du Vestibule) ; round (Nuit) +1 après le dernier.
